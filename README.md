# План питания

Прототип приложения для iPhone: база рецептов, меню на неделю, дни готовки и подсчет КБЖУ.

## Что уже есть

- создание, редактирование и удаление рецептов;
- добавление ингредиентов с КБЖУ на 100 г и весом;
- автоматический расчет КБЖУ всего блюда и одной порции;
- меню на неделю по дням и приемам пищи;
- выбор дней, когда готовишь;
- отметка блюда как `готово`, если оно назначено на день готовки;
- подсчет КБЖУ за день и за неделю;
- сохранение данных в локальную базу браузера `IndexedDB`;
- автоматический перенос старых данных из `localStorage` при первом запуске новой версии.

## Где хранятся данные

Приложение использует локальную базу `IndexedDB` прямо в браузере. Это работает на GitHub Pages, в Safari на iPhone и в режиме приложения, добавленного на экран "Домой".

Важно: это локальная база конкретного устройства и браузера. Данные на iPhone и компьютере не синхронизируются между собой автоматически. Для синхронизации между устройствами позже понадобится облачная база, например Supabase или Firebase.

## Как открыть сейчас

Открой `index.html` в браузере. Сборка не нужна.

Для локальной проверки через небольшой сервер:

```bash
node scripts/dev-server.mjs
```

После запуска открой `http://127.0.0.1:4173`.

## Как упаковать под iPhone и AltStore

Сам код уже сделан как web-first приложение. Чтобы получить `.ipa`, удобнее завернуть его в Capacitor на macOS:

```bash
npm install @capacitor/core @capacitor/cli @capacitor/ios
npx cap add ios
npx cap open ios
```

В Xcode выбери свой Apple ID в Signing, собери архив и экспортируй `.ipa`. Затем открой `.ipa` через AltStore на iPhone.

На Windows можно продолжать разрабатывать интерфейс и логику, но финальная iOS-сборка требует macOS/Xcode или CI с macOS.
